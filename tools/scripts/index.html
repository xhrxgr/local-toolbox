Windows 本地小工具：下载后在本机运行，不联网、不上传任何数据。 每个脚本只改动对应的注册表项，并附带恢复方式。
/
使用说明
  • 下载后若双击没有反应或提示「已阻止无法运行此脚本」：右键文件 → 属性 → 常规 → 勾选「解除锁定」→ 确定，再重新运行。
  • 需要管理员权限的脚本，右键 →「以管理员身份运行」；脚本开头也会检查权限并给出提示。
  • 三个脚本都是单个 .bat 文件，下载后直接双击运行，不用解压、不用把多个文件放一起。
  • 三个脚本都可复原：时钟脚本再运行一次即切回；热点上限脚本按首次备份还原原始值；自启脚本卸载时可连文件一起删干净。
  • 修改移动热点的连接数上限后，重开移动热点或重启电脑生效。
  • 任务栏时钟脚本会自动重启资源管理器使设置生效，桌面图标会短暂消失属正常现象。
